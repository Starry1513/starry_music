# 群星音乐 Starry Music

用手机、平板或电脑遥控家里的 DLNA 播放器：在播放器的曲库里点歌，在手机上看同步歌词，管理歌单，和播放器互传文件。主要在 **A&K ACRO CA1000T** 上实测，其他支持 DLNA / UPnP 的播放器大多也能用（见下面的兼容表）。

声音始终由播放器自己放，手机只是遥控器：音质不经过手机，手机锁屏、离开也不影响播放。

两个版本：

| 版本 | 跑在哪 | 怎么打开 |
|---|---|---|
| 电脑版 | Windows / macOS / Linux，需要 Node.js 18+，没有其他依赖 | `node server.js`，浏览器打开 `http://电脑IP:8790/?k=口令` |
| 手机 / 平板版 | Android 10+ 的 App（`android/StarryMusic.apk`） | 装好直接打开，不需要电脑 |

两个版本的界面和接口是同一套（`ui/music.html` + `/api/music/*`）。电脑版也可以挂进「群星」中台（`integrations/constellation.js`）。

## 功能

- **曲库**：按播放器自己的分类浏览，包括文件夹、歌手、专辑、全部歌曲、歌单。
- **播放控制**：
  - 播放、暂停、拖进度、上一首 / 下一首。
  - 音量和静音，可以用手机的音量键调播放器音量。
  - 响度补偿。
  - 播放顺序：顺序、列表循环、单曲循环、随机。
  - 睡眠定时：最后 20 秒慢慢变小声；也可以设成"播完这首就停"。
- **队列**：插到下一首、加到末尾、拖动排序、移除。程序重启后队列还在。
- **歌词**：
  - 播放时同时在 LRCLIB 和网易云在线搜同步歌词，自动按歌名、歌手、时长挑最合适的一版，并转成简体（日文不转）。
  - 外文歌有翻译的会显示中文翻译。
  - 匹配不对时点「换歌词」自己搜、自己选，系统会记住你选的那一版。也可以把某首设成不显示歌词。
  - 歌词正文不存到本地，只记"这首用哪一版"。
- **英文单词点查**（设置里可以关）：
  - 歌词里的英文单词点一下就能看释义。
  - 「＋生词本」会把单词加进群星「单词复习」，和欧路同步来的词一起复习；没接群星时先存在本机。
- **歌单**：
  - 歌单存在播放器的 `/Playlists/*.m3u` 里，机器上也能直接点。程序里同时留一份副本，两边都能改。
  - 打开歌单时先显示副本，再悄悄和机器核对。
- **自动歌单**：「最近常听」「很久没听」根据听歌记录每天更新，也会写到播放器上。
- **听歌统计**：
  - 记录每天听了什么、听了多久，直接在机器上点的歌也算。
  - 统计显示在群星「综合」页和设置里。
- **整理（补全歌曲信息）**：
  - 选歌（缺信息的歌 / 刚导入的 / 某个文件夹，可多选）→ 在网易云和 Apple Music 里查 → 每首显示改前改后（歌名、歌手、专辑、曲序、年份、封面）。
  - 把握大的默认勾上，拿不准的不改；可以「换一个」版本，或点字直接改。确认后写进文件。
  - 写入在电脑上进行（需要 Python，`tools/tagfix.py`）。音乐数据不动，原来的信息留底可还原。
  - 歌手名会统一成同一种写法（Leslie Cheung → 张国荣、G.E.M. → 邓紫棋…）。你改过的写法会被记住，以后自动套用。
  - 上传歌曲后会提示"现在补全"。
- **专辑缺歌**：按网易云 / Apple Music 的专辑曲目表对照，看曲库里每张专辑缺哪几首。
- **传输**：和播放器互传文件，显示上传、下载两段的实时速度。安卓版直接手机 ⇄ 播放器，不经过电脑；在别的 App 里「分享 → 传到播放器」也能传。
- **安卓版额外**：通知栏 / 锁屏播放控制，耳机按键，音量键控制播放器音量。

## 兼容性

| 功能 | 需要播放器提供 | CA1000T 实测 | 一般 DLNA 播放器 |
|---|---|---|---|
| 发现播放器 | SSDP（UPnP 组播） | ✓ | ✓ |
| 播放 / 暂停 / 进度 | AVTransport | ✓ | ✓ |
| 音量 / 静音 | RenderingControl | ✓ | ✓ |
| 响度补偿 | RenderingControl `SetLoudness` | ✓ | 少数支持 |
| 浏览曲库 | 播放器自带 MediaServer（ContentDirectory） | ✓（AK Connect） | 视机型；没有的话只能遥控 |
| 无缝下一首 | `SetNextAVTransportURI` 并且真的会自动接 | ✗：收下了但不接。程序在曲末快速补推，间隔约 1 秒 | 视机型 |
| 歌单写回机器 | 能写机器存储（这里用 FTP） | ✓（AK File Drop） | 一般没有 |
| 传文件 | FTP | ✓（AK File Drop，端口 1212） | 一般没有 |
| 改 EQ、增益等设备设置 | 私有协议 | ✗（没有公开接口） | ✗ |

CA1000T 已知的问题：

- 推 DSD（dsf/dff）播放曾经把它卡死，所以默认不推。要推的话在配置里打开 `allowDsd`。
- 机器息屏后 FTP 会断，传文件时让它亮着屏。
- 它的 FTP 删文件夹会连里面的文件一起删。程序删文件夹前会先检查，不是空的就不删。
- 更新曲库（媒体扫描）时，"清除歌单"默认是勾上的，扫描前记得取消，否则歌单会被清掉。

## 配置

电脑版：把 `config.example.json` 复制成 `config.json` 再改。都不填也能用：会自动找播放器，FTP 用 admin / admin。

```json
{
  "server": { "host": "0.0.0.0", "port": 8790, "token": "" },
  "player": {
    "name": "",
    "ip": "",
    "allowDsd": false,
    "internalPath": "/storage/emulated/0",
    "sdPath": "/storage/sdcard1",
    "ftp": { "port": 1212, "user": "admin", "pass": "admin" },
    "lyrics": true,
    "playlistAlbums": [],
    "python": ""
  },
  "hub": { "url": "", "token": "" }
}
```

| 配置项 | 说明 |
|---|---|
| `token` | 访问口令。留空就自动生成，存在 `data/token.txt`。本机访问不需要口令 |
| `name` / `ip` | 家里有好几台播放器时用来指定一台 |
| `sdPath` | 存储卡在播放器上的路径。歌单里的路径要靠它对上，形式一般是 `/storage/XXXX-XXXX` |
| `playlistAlbums` | 被下载软件写成"专辑名"的歌单名（比如网易云歌单名），整理时当作"没有专辑" |
| `python` | 写入歌曲信息用的 Python（默认 `python3` / Windows 上 `py`），需要 `pip install -r tools/requirements.txt` |
| `hub` | 填群星中台的地址和口令后，生词会加进群星的单词复习 |

安卓版：在设置（右上角齿轮）里填播放器 IP（留空就自动找）、"分享"上传的目标文件夹，以及群星地址和口令（可以不填）。

页面设置里还有三个开关：英文单词点查、显示歌词翻译、自动歌单写到播放器。

## 传输

只有一条路：**设备 ⇄ 播放器**，用的是播放器自带的 **AK File Drop**（FTP）。电脑版是"浏览器 → 电脑上的程序 → 播放器"，安卓版是"App → 播放器"直连。不做设备之间的互传，那是 KDE Connect / 群星链接的事。

- File Drop 是明文 FTP，只适合在家里的局域网用，不要把端口映射到外网。
- 下载会等同一个文件的上传结束后再开始，避免刚传上去马上下载时读到半个文件。
- 断线后自动重试一次。
- 删文件夹前先检查是否为空（见上面的 CA1000T 已知问题）。

2026-11-19 实测，家里 Wi-Fi，CA1000T 亮屏，文件 md5 前后一致：

| 方向 | 文件 | 平均速度 | 峰值 |
|---|---|---|---|
| 电脑 → CA1000T | 100 MB | 1.8 MB/s | 2.0 MB/s |
| CA1000T → 电脑 | 100 MB | 1.6 MB/s | 2.3 MB/s |
| 手机 App → CA1000T | 40 MB | 1.6 MB/s | 3.4 MB/s |
| CA1000T → 手机 App | 40 MB | 1.4 MB/s | 2.5 MB/s |
| 平板 App → CA1000T | 40 MB | 1.8 MB/s | 1.9 MB/s |
| CA1000T → 平板 App | 40 MB | 2.1 MB/s | 2.4 MB/s |

瓶颈在播放器的 FTP 服务，大约 2 MB/s。一首 30 MB 的 FLAC 要传 15 秒左右。

## 构建安卓版

不用 Gradle。需要 JDK 17、`android-34.jar`、`dalvik-exchange`（dx）、`aapt`、`zipalign`、`apksigner`：

```bash
cd android
AJ=/path/to/android-34.jar KS=/path/to/your.keystore ./build.sh
```

因为用的是 dx，代码里只能写匿名类，不能写 lambda。

## 目录

```
server.js                 电脑版服务
core/music.js             核心：发现、播放控制、队列、曲库、歌单、FTP 传输
core/extras.js            多来源歌词和换歌词、单词点查、听歌统计、自动歌单、设置
core/ftp.js               小 FTP 客户端
core/opencc_t2cn.js       繁转简（opencc-js）
ui/music.html             界面（电脑版和安卓版共用）
integrations/             挂进群星中台的外壳
android/                  安卓版（Java，无 Gradle）
tools/tagfix.py           补写/统一歌曲标签（歌名、歌手、专辑），原标签留底可还原
```

## 隐私

- 所有数据都存在自己的设备上：队列、歌单副本、听歌统计、换歌词的选择。
- 只有两种联网：查歌词（LRCLIB、网易云）和查单词（有道）。发出去的只有歌名、歌手、时长或单词本身。
